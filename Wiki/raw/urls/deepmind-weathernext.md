# WeatherNext 3 — Google DeepMind

Captura de la página de producto/anuncio de Google DeepMind para WeatherNext, cuya
versión actual descrita es **WeatherNext 3**.

## Contenido relevante

**Organización:** Google DeepMind. No se listan autores individuales.

**Descripción:** WeatherNext 3 se presenta como "el primer modelo global del clima que
genera pronósticos cada hora del día". Es un modelo de ensamble que procesa imágenes
satelitales crudas directamente para producir predicciones meteorológicas a distintas
resoluciones, en vez de depender únicamente de métodos numéricos tradicionales de
predicción del clima (NWP).

**Mejoras reportadas frente a métodos anteriores** (sin métricas/benchmarks numéricos en
esta página):

1. **Resolución temporal** — genera pronósticos cada hora del día, en vez de en
   actualizaciones periódicas tradicionales.
2. **Resolución espacial** — predice todas las variables de superficie, incluyendo
   temperatura y humedad a 5km de resolución, y otras variables como viento a 10km.
3. **Generalización** — entrega pronósticos precisos incluso en ubicaciones que el
   modelo no vio durante el entrenamiento.

**Disponibilidad:**
- Integrado en productos de Google: Search, Maps, Gemini.
- Acceso empresarial vía BigQuery, Earth Engine, Google Maps Platform, Google Cloud Storage.
- Documentación para desarrolladores: developers.google.com/weathernext/guides/models
- Plataforma experimental "Weather Lab" para explorar pronósticos.
- Caso de estudio mencionado: uso por el National Hurricane Center con el huracán Melissa.
- No se listan enlaces directos a papers académicos o repos de código en esta página.
